Implemente, em Java, uma aplicação desktop do jogo de cartas Paciência (variante Klondike), com interface gráfica, que atenda integralmente aos requisitos funcionais e não funcionais descritos no arquivo REQUISITOS.md, na raiz deste diretório.

Restrições técnicas:
- Java 21, com build em Maven.
- Interface gráfica em JavaFX.
- O projeto deve compilar e executar a partir da raiz com: mvn clean javafx:run
- Identificadores de código (pacotes, classes, métodos, variáveis) em inglês.
- Nenhuma dependência além das necessárias para a interface gráfica e para testes.
- A aparência das cartas deve ser desenhada pela própria aplicação ou gerada por você. Não baixe imagens ou outros recursos.

Regras de trabalho:
- Use como especificação apenas o REQUISITOS.md e este prompt. Não pesquise na web e não utilize código de terceiros.
- Atenda a cada requisito (RF01 a RF32 e RNF01 a RNF05) exatamente como está escrito. Não adicione funcionalidades que os requisitos não pedem.
- Se algum requisito for ambíguo, declare a interpretação adotada no plano, antes de implementar.
- Antes de escrever código, apresente um plano com: estrutura de pacotes, principais tipos e suas responsabilidades, e como cada requisito será atendido.
- Depois da implementação, confirme que o projeto compila e que a aplicação inicia com o comando acima.
